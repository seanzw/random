# How GPGPU-Sim Decodes and Registers PTX Functions from Binary

This is the note generated by claude while helping me implement `cuModuleLoad()` and `cuModuleGetFunction()`.
**Use it as a reference with caution!**

## Overview

GPGPU-Sim extracts PTX (Parallel Thread Execution) functions from CUDA binaries and converts them into an internal `function_info` representation that can be executed by the simulator. The process involves several key stages: **binary extraction**, **parsing**, **decoding**, and **registration**.

---

## 1. Binary Extraction Phase

### 1.1 Using cuobjdump

The primary mechanism for extracting PTX code from CUDA binaries is the **cuobjdump** tool.

**File**: `libcuda/cuda_runtime_api.cc`

**Key Functions**:
- `cuda_runtime_api::extract_code_using_cuobjdump()` - Main entry point
- `cuda_runtime_api::extract_code_using_cuobjdump_internal()` - Implementation
- `cuda_runtime_api::extract_ptx_files_using_cuobjdump()` - Per-file extraction

**Process**:
```cpp
void cuda_runtime_api::extract_code_using_cuobjdump_internal(
    CUctx_st *context, std::string &app_binary,
    std::function<void(CUctx_st *)> ctx_extract_ptx_func)
```

The function executes system command:
```bash
$CUDA_INSTALL_PATH/bin/cuobjdump -ptx -elf -sass [-all] <app_binary>
```

This extracts:
- **PTX sections**: Intermediate representation of GPU code
- **ELF sections**: Object file information
- **SASS sections**: GPU assembly code

### 1.2 Output Processing

The cuobjdump output is parsed by a **Lex/Yacc parser**:

**File**: `libcuda/cuobjdump.l` and `libcuda/cuobjdump.y`

```cpp
struct cuobjdump_parser parser;
parser.elfserial = 1;
parser.ptxserial = 1;
cuobjdump_lex_init(&(parser.scanner));
cuobjdump_set_in(cuobjdump_in, parser.scanner);
cuobjdump_parse(parser.scanner, &parser, cuobjdumpSectionList);
```

**Result**: Multiple `cuobjdumpSection` objects (either `cuobjdumpPTXSection` or `cuobjdumpELFSection`)

## 2. PTX File Processing

### 2.1 Version/Architecture Selection

**File**: `libcuda/cuda_runtime_api.cc` (lines 700-800)

The system selects appropriate PTX based on GPU compute capability:

```cpp
void **cudaRegisterFatBiaryInternal_impl(
    void *fatCubin, gpgpu_context *gpgpu_ctx, ...)
{
    __cudaFatCudaBinary *info = (__cudaFatCudaBinary *)fatCubin;
    unsigned num_ptx_versions = 0;
    unsigned max_capability = 0;
    
    // Iterate through PTX versions (compute_20, compute_30, etc.)
    while (info->ptx[num_ptx_versions].gpuProfileName != NULL) {
        unsigned capability = 0;
        sscanf(info->ptx[num_ptx_versions].gpuProfileName, 
               "compute_%u", &capability);
        
        // Select highest capability <= forced_max_capability
        if (capability > max_capability) {
            max_capability = capability;
            selected_capability = num_ptx_versions;
        }
        num_ptx_versions++;
    }
}
```

### 2.2 PTX String Loading

**File**: `src/cuda-sim/ptx_loader.cc`

```cpp
symbol_table *gpgpu_context::gpgpu_ptx_sim_load_ptx_from_string(
    const char *p, unsigned source_num)
{
    // Create symbol table for this PTX
    symbol_table *symtab = init_parser(buf);

    ptx_lex_init(&(ptx_parser->scanner));
    ptx__scan_string(p, ptx_parser->scanner);

    if (errors) {
        // Extract PTX to error file for debugging
        // ...abort
    }
    
    ptx_lex_destroy(ptx_parser->scanner);
    return symtab;
}
```

## 3. PTX Parsing Phase

### 3.1 Lexer and Parser

**Files**: 
- `src/cuda-sim/ptx.l` - Lexer (Lex file)
- `src/cuda-sim/ptx.y` - Parser (Yacc file)
- `src/cuda-sim/ptx_parser.cc` - Parser implementation
- `src/cuda-sim/ptx_parser.h` - Parser interface

### 3.2 Parser Structure

**Key Classes**:

**`ptx_recognizer`** (`src/cuda-sim/ptx_parser.h`):
- Maintains parsing state (opcodes, operands, directives)
- Global symbol table and current symbol table
- Instruction list accumulation
- Function information building

**`symbol_table`**:
- Stores variable declarations, function signatures
- Maintains scope hierarchy (global → function → block scopes)

### 3.3 Parsing Flow

```cpp
void ptx_recognizer::start_function(int entry_point)
{
    // Initialize new function context
    g_func_info = new function_info(name, entry_point);
    g_current_symbol_table = new symbol_table(...);
}

void ptx_recognizer::add_directive()
{
    // Process .entry, .func directives
    // Register parameters, return types
}

void ptx_recognizer::end_function()
{
    // Finalize function
    g_max_regs_per_thread = mymax(g_max_regs_per_thread, 
                                  g_current_symbol_table->next_reg_num() - 1);
    
    // Add accumulated instructions to function
    g_func_info->add_inst(g_instructions);
    g_instructions.clear();
    
    // Assemble the PTX into IR
    gpgpu_ptx_assemble(g_func_info->get_name(), g_func_info);
    
    g_current_symbol_table = g_global_symbol_table;
}
```

## 4. Instruction Decoding Phase

### 4.1 Instruction Creation

**File**: `src/cuda-sim/cuda-sim.cc`

During parsing, instructions are created and then **pre-decoded**:

```cpp
class ptx_instruction : public warp_inst_t
{
    virtual void pre_decode();
};

void ptx_instruction::pre_decode()
{
    // Convert PTX operand information to architecture registers
    // Set opcode and latency information
    // Lookup operand memory/register details
    
    set_opcode_and_latency();
    set_bar_type();
    set_fp_or_int_archop();
    set_mul_div_or_other_archop();
    
    // Fill architectural register fields
    for (unsigned i = 0; i < num_operands; i++) {
        operand_info &o = operands[i];
        if (o.get_key().is_reg()) {
            arch_reg.src[i] = o.arch_reg_num();
        }
    }
    
    // Get reconvergence PC
    reconvergence_pc = gpgpu_ctx->func_sim->get_converge_point(pc);
    
    m_decoded = true;
}
```

### 4.2 Function Assembly and Pre-decoding

**File**: `src/cuda-sim/ptx_ir.cc`

```cpp
void function_info::do_pdom()
{
    // Dominator and post-dominator analysis for reconvergence points
    for (unsigned i = 0; i < m_instr_mem_size; i++) {
        ptx_instruction *pI = m_instr_mem[i];
        
        pI->pre_decode();  // Decode each instruction
        update_dyn_inst(pI);
    }
    
    printf("GPGPU-Sim PTX: ... done pre-decoding instructions for '%s'.\n",
           m_name.c_str());
    m_assembled = true;
}
```

## 5. Registration Phase

### 5.1 Function Registration in Context

**File**: `libcuda/cuda_runtime_api.cc`

When `cudaRegisterFunction` is called:

```cpp
void cudaRegisterFunctionInternal(
    void **fatCubinHandle, const char *hostFun,
    char *deviceFun, const char *deviceName, ...)
{
    CUctx_st *context = GPGPUSim_Context(ctx);
    unsigned fat_cubin_handle = (unsigned)(unsigned long long)fatCubinHandle;
    
    printf("GPGPU-Sim PTX: __cudaRegisterFunction %s : "
           "hostFun 0x%p, fat_cubin_handle = %u\n",
           deviceFun, hostFun, fat_cubin_handle);
    
    // Parse cuobjdump if using that method
    if (context->get_device()->get_gpgpu()->get_config().use_cuobjdump())
        ctx->cuobjdumpParseBinary(fat_cubin_handle);
    
    // Register the function mapping
    context->register_function(fat_cubin_handle, hostFun, deviceFun);
}
```

### 5.3 Runtime Kernel Execution

When `cudaLaunch` is called:

```cpp
cudaError_t cudaLaunchInternal(const char *hostFun, gpgpu_context *gpgpu_ctx)
{
    CUctx_st *context = GPGPUSim_Context(ctx);
    
    // Get the kernel info
    function_info *entry = context->get_kernel(hostFun);
    
    // Create grid representation
    kernel_info_t *grid = ctx->api->gpgpu_cuda_ptx_sim_init_grid(
        hostFun, config.get_args(), config.grid_dim(), 
        config.block_dim(), context);
    
    // For performance simulation, compute reconvergence points
    if (!kernel_func_info->is_pdom_set()) {
        printf("GPGPU-Sim PTX: finding reconvergence points for '%s'...\n",
               kname.c_str());
        kernel_func_info->do_pdom();
        kernel_func_info->set_pdom();
    }
    
    // Push kernel to stream queue
    stream_operation op(grid, ctx->func_sim->g_ptx_sim_mode, stream);
    ctx->the_gpgpusim->g_stream_manager->push(op);
}
```

## 6. Data Structures

### 6.1 Key Classes

**`function_info`** (`src/cuda-sim/ptx_ir.h`):
- Function name and entry point
- Instruction memory (`m_instr_mem`)
- Symbol table scope
- Kernel metadata (registers, shared memory, etc.)
- Pre-decoded instructions

**`ptx_instruction`** (`src/cuda-sim/ptx_ir.h`):
- Extends `warp_inst_t` 
- PTX operands and memory/register mappings
- Architectural register fields
- Pre-decoded status
- Reconvergence PC information

**`symbol_table`** (`src/cuda-sim/ptx_ir.h`):
- Variable/register symbol lookup
- Scope hierarchy (parent pointers)
- Name-to-symbol mapping

**`operand_info`**:
- Register index or memory address
- Type information
- Architecture register number

│ 1. BINARY EXTRACTION                                            │
│ ┌──────────────────────────────────────────────────────────────┐
│ │ cuobjdump -ptx -elf -sass <binary>                           │
│ │ → Extracts PTX strings for all SM versions                   │
│ └──────────────────────────────────────────────────────────────┘
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 2. VERSION SELECTION                                            │
│ ┌──────────────────────────────────────────────────────────────┐
│ │ Select highest SM version ≤ forced_max_capability            │
│ │ (e.g., compute_70 for sm_70 GPU)                             │
│ └──────────────────────────────────────────────────────────────┘
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 3. PTX PARSING                                                  │
│ ┌──────────────────────────────────────────────────────────────┐
│ │ ptx_parse() via Lex/Yacc                                      │
│ │ → ptx_recognizer::start_function()                            │
│ │ → Process directives, parameters, instructions               │
│ │ → ptx_recognizer::end_function()                              │
│ │ → gpgpu_ptx_assemble()                                        │
│ └──────────────────────────────────────────────────────────────┘
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 4. INSTRUCTION DECODING                                         │
│ ┌──────────────────────────────────────────────────────────────┐
│ │ function_info::do_pdom()                                      │
│ │ → ptx_instruction::pre_decode()                               │
│ │ → Map operands to architecture registers                      │
│ │ → Set opcode/latency                                          │
│ │ → Compute reconvergence points                                │
│ └──────────────────────────────────────────────────────────────┘
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 5. REGISTRATION                                                 │
│ ┌──────────────────────────────────────────────────────────────┐

┌─────────────────────────────────────────────────────────────────┐
│ 6. RUNTIME EXECUTION                                            │
│ ┌──────────────────────────────────────────────────────────────┐
│ │ cudaLaunch(hostFun)                                           │

## 9. Example: Complete Flow for a Kernel

```
Binary: myapp (CUDA executable)
  ↓
cuobjdump extracts: myapp_kernel_sm70.ptx
  ↓
PTX Parser (Lex/Yacc):
  - Recognizes ".entry myapp_kernel" directive
  - Processes parameters: .param .u64 %param0
  - Creates ptx_instruction objects for each PTX instruction
  - Builds function_info("myapp_kernel", entry_point=0)
  ↓
Instruction Decoding:
  - function_info::do_pdom()
  - Each ptx_instruction::pre_decode():
    * Map %r0 → register 0
    * Map @%p0 → predicate register 0
    * Set latency (ld.u64 = 4 cycles)
  ↓
Registration:
  - context->register_function(0x7fff... → "myapp_kernel")
  ↓
Runtime:
  - cudaLaunch(0x7fff...)
  - get_kernel(0x7fff...) → function_info("myapp_kernel")
  - Create kernel_info_t grid
  - Execute threads on GPU simulator
```

## 10. Important Config Options

From `src/cuda-sim/ptx_loader.cc`:

- `-gpgpu_ptx_use_cuobjdump`: Enable cuobjdump-based extraction
- `-save_embedded_ptx`: Save PTX files for debugging
- `-keep`: Keep intermediate files
- `-gpgpu_ptx_save_converted_ptxplus`: Save PTXPlus conversion
- `-gpgpu_occupancy_sm_number`: SM version for ptxas occupation queries
